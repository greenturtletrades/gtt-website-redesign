# Docs

This folder contains reference material that is useful for humans but not required at runtime.

- `architecture.md` explains the full system structure and how the services connect.
- `getting-started.md` explains local setup, startup order, and what each service needs.
- `workflows.md` explains the main end-to-end product and technical flows.
- `analytics/` contains analytics-side reference files and archived model notes.
- `frontend/` contains product and implementation notes that were previously mixed into frontend source.
- `notes/` contains historical implementation notes and handoff material. Some path references there are intentionally archival.
