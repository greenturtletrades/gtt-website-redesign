# API Helpers

This folder contains thin frontend clients for backend endpoints.

- `auth.ts`, `subscription.ts`, and `settings.ts` cover logged-in account flows
- `contact.ts`, `waitlist.ts`, and `traderApplication.ts` cover public form submissions
- `analysis.ts` and `trades.ts` cover analytics and journal-related calls
- `client.ts` centralizes the shared request helpers and error handling
