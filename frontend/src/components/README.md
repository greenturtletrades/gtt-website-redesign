# Components

This folder mixes three types of frontend components:

- Page-level screens grouped by purpose
- Flow-specific components such as auth, subscription, onboarding, and trader modals
- Shared UI primitives under `ui/`

Useful subfolders:

- `marketing/` contains the public landing experience, header, footer, and contact page
- `legal/` contains policy and disclosure pages
- `admin/` contains admin login and dashboard components
- `auth/` contains trader auth and post-checkout flow components
- `trader/` contains the analytics dashboard and account tools
- `onboarding/` contains trader application flow components
- `ui/` contains reusable Radix-style UI primitives
- `figma/` contains export-era helper components that support imported design assets
